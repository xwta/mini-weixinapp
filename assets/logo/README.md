# Logo 资源说明

本目录存放谱灵 AI 小程序可直接引用的 Logo 级别前端资源。

## 文件清单

- `logo-horizontal.svg`：横版 Logo，适合首页顶部、启动页、品牌展示区域。
- `logo-icon.svg`：方形图标，适合小程序图标、头像、功能入口图标、占位图。
- `puling-logo.svg`：早期横版 Logo 设计稿备份。
- `puling-icon.svg`：早期图标设计稿备份。

## 使用建议

```html
<image src="/assets/logo/logo-horizontal.svg" mode="aspectFit" />
<image src="/assets/logo/logo-icon.svg" mode="aspectFit" />
```

## 尺寸建议

| 资源 | 建议尺寸 |
|---|---|
| logo-horizontal.svg | 720 x 220 |
| logo-icon.svg | 256 x 256 |

## 颜色

- 品牌绿：`#1E7A5A`
- 深墨绿：`#123C32`
- 浅薄荷绿：`#E8F7F0`
- 奶油黄：`#FFF3CF`
