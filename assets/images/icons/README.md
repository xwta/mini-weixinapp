# 图标级图片资源

本目录存放谱灵 AI 小程序可直接引用的图标级 SVG 图片。

## 文件清单

- `icon-ai-write.svg`：AI 写歌图标。
- `icon-chord.svg`：配和弦图标。
- `icon-tab.svg`：吉他谱图标。
- `icon-practice.svg`：练习图标。

## 使用示例

```html
<image src="/assets/images/icons/icon-ai-write.svg" mode="aspectFit" />
<image src="/assets/images/icons/icon-chord.svg" mode="aspectFit" />
```

## 说明

图标尺寸统一为 64 x 64，圆角底色风格与小程序整体视觉保持一致。
