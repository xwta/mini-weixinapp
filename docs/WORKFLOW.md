# 开发协作流程

## GitHub 提交流程

本项目后续开发默认直接提交到 GitHub 仓库：

```text
xwta/mini-weixinapp
```

除非涉及以下高风险操作，否则不再额外要求用户确认：

- 删除大量文件
- 覆盖核心业务代码
- 修改仓库权限
- 删除分支或强制推送
- 更改生产环境配置
- 暴露密钥、Token、账号密码等敏感信息

## 默认执行方式

后续开发按照以下方式推进：

1. 明确当前任务目标。
2. 直接创建或更新代码文件。
3. 提交到 `main` 分支。
4. 在回复中汇总已完成内容、文件路径和下一步建议。

## 提交规范

推荐提交前缀：

```text
backend: 后端功能
frontend: 前端功能
admin: 后台功能
assets: 静态资源
docs: 文档
fix: 修复
chore: 工程配置
```

## 当前约定

- 后端：Python + FastAPI + MySQL
- 前端：uni-app / Vue3
- 数据库：MySQL 8.0
- 默认分支：main
- 默认开发模式：直接提交，不重复确认
