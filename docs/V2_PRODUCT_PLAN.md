# 谱灵 AI V2 产品方案

## 1. V2 定位

V2 从传统多页面工具型小程序，升级为对话式 AI 吉他伙伴。

核心口号：

```text
输入灵感，生成曲谱，跟着练会。
```

产品目标：

```text
让用户像和音乐伙伴聊天一样完成写歌、搜谱、配和弦、练习和分享。
```

## 2. 核心变化

V1 更像工具集合：

```text
首页 / 搜谱 / AI创作 / 曲谱详情 / 评论 / 我的
```

V2 更像 AI 工作台：

```text
谱灵对话
  ↓
AI 识别意图
  ↓
自动切换模式
  ↓
生成结果卡片
  ↓
保存 / 练习 / 发布到社区
```

## 3. 一级 Tab

一级 Tab 只保留三个：

```text
谱灵
社区
我的
```

说明：

```text
记录不是一级 Tab
记录是谱灵首页内的二级页面
```

## 5. 谱灵首页

定位：AI 对话工作台。

核心模块：

```text
顶部模式切换
AI 对话区
结果卡片
输入框
记录入口
底部 Tab
```

模式：

```text
AI写歌
搜谱
配和弦
练习助手
乐理问答
```

典型流程：

```text
用户输入：帮我写一首毕业民谣
  ↓
AI 识别为 AI写歌
  ↓
生成歌曲卡片
  ↓
用户点击查看曲谱 / 练习 / 保存 / 发布
```

## 6. 记录页

记录页是谱灵首页的二级页面，不出现在底部 Tab。

入口：

```text
谱灵首页右上角记录按钮
或侧滑抽屉
```

记录分类：

```text
全部
对话
创作
搜谱
练习
收藏
```

每条记录可继续上下文：

```text
继续对话
继续修改曲谱
继续练习
重新生成
```

## 7. 社区首页

定位：音乐灵感广场。

核心模块：

```text
顶部搜索框
推荐 / 关注 / 最新 / 热门
作品流
发布入口
点赞 / 评论 / 收藏 / 分享
```

社区搜索支持：

```text
歌曲
用户
话题
和弦
帖子
```

## 8. 我的首页

定位：个人资产中心。

核心模块：

```text
用户信息
AI 额度
我的作品
我的收藏
我的发布
练习记录
消息通知
会员中心
设置中心
帮助反馈
```

## 9. 内容卡片

AI 结果卡片需要支持：

```text
试听
查看曲谱
继续修改
开始练习
保存
发布到社区
```

社区作品卡片需要支持：

```text
播放
和弦预览
点赞
评论
收藏
分享
关注作者
```
