# 谱灵 AI 微信小程序产品需求文档 V1.0

## 一、产品名称

暂定名称：谱灵 AI

备选名称：

- 弦上 AI
- 吉他谱工坊
- AI 弹唱星球
- 一键写谱
- 弦音助手

## 二、产品定位

谱灵 AI 是一款面向吉他弹唱用户的微信小程序，支持 AI 写歌、AI 生成吉他谱、AI 配和弦、弹唱练习和作品收藏。

核心价值：

> 让用户从一句灵感，生成一首可以弹唱的歌。

## 三、目标用户

### 1. 吉他新手

特点：

- 会基础和弦
- 想快速找到适合自己的谱
- 不懂乐理
- 需要简单、可弹、好上手

需求：

- 自动生成简单和弦
- 给出变调夹建议
- 提供右手节奏型
- 有练习模式

### 2. 弹唱爱好者

特点：

- 经常找谱、收藏谱
- 喜欢翻唱
- 想要不同风格版本

需求：

- 一键生成新手版/进阶版
- 支持升降调
- 自动滚谱
- 收藏歌单

### 3. 原创音乐爱好者

特点：

- 想写歌但不会编曲
- 有歌词、灵感、情绪
- 想生成一首完整弹唱作品

需求：

- AI 写歌词
- AI 配和弦
- AI 生成主歌/副歌/桥段
- 保存原创作品
- 导出图片或 PDF

### 4. 内容创作者

特点：

- 小红书、抖音、视频号创作者
- 需要原创歌曲、弹唱内容
- 想快速生成内容素材

需求：

- 一键生成原创弹唱歌
- 生成分享海报
- 生成短视频文案
- 生成封面标题

## 四、产品核心价值

| 用户痛点 | 产品解决方案 |
|---|---|
| 找谱麻烦 | AI 直接生成可弹唱谱 |
| 不懂乐理 | 自动推荐调式、和弦、节奏 |
| 曲谱太难 | 一键生成新手版 |
| 想写歌但不会编曲 | AI 写词 + 配和弦 |
| 练习不方便 | 自动滚谱、节拍器、收藏 |
| 分享成本高 | 一键生成曲谱海报 |

产品核心卖点：

```text
输入一句话，AI 生成一首能弹唱的歌。
```

## 六、MVP 版本范围

### MVP 必做功能

| 模块 | 功能 | 优先级 |
|---|---|---|
| 微信登录 | 微信授权登录 | P0 |
| 首页 | AI 创作入口、推荐内容 | P0 |
| AI 写歌 | 输入主题生成歌词+和弦 | P0 |
| AI 配谱 | 粘贴歌词生成吉他谱 | P0 |
| 曲谱详情 | 展示歌词、和弦、调式、节奏 | P0 |

| 我的作品 | 查看历史生成内容 | P0 |
| 分享 | 生成分享图/转发小程序 | P1 |
| 次数限制 | 免费次数、会员次数 | P1 |
| 会员中心 | 购买生成次数/会员 | P1 |

### MVP 暂不做

| 功能 | 原因 |
|---|---|
| 音频扒谱 | 技术难度高 |
| 哼唱识别 | 算法成本高 |
| 大型曲库 | 版权风险高 |
| 社区评论 | 审核成本高 |
| 多乐器编曲 | 超出首版范围 |
| 原唱伴奏生成 | 成本和版权复杂 |

## 八、AI 功能设计

### 1. AI 写歌

输入：

```text
主题：毕业、夏天、遗憾
风格：校园民谣
难度：新手
```

输出：

- 歌名
- 歌词
- 和弦
- 曲式结构
- 调式
- BPM
- 变调夹建议
- 节奏型
- 练习建议

输出 JSON 结构：

```json
{
  "title": "夏天没说完的话",
  "style": "校园民谣",
  "key": "C",
  "bpm": 86,
  "capo": "2品",
  "difficulty": "新手",
  "strumming": "↓ ↓↑ ↑↓↑",
  "chords": ["C", "G", "Am", "F", "Em"],
  "sections": [
    {
      "name": "主歌",
      "lines": [
        {
          "chordLine": "C              G",
          "lyricLine": "操场边的风吹过了盛夏"
        },
        {
          "chordLine": "Am             F",
          "lyricLine": "你低头笑着没有回答"
        }
      ]
    }
  ],
  "practiceTips": [
    "先用每小节一下的方式练习和弦转换",
    "熟悉后再加入完整扫弦节奏"
  ]
}
```

### 2. AI 配和弦

用户输入：

```text
窗外的风吹过夏天
你低头笑得很浅
我把没说出口的话
写进旧吉他的弦
```

AI 输出：

```text
C              G
窗外的风吹过夏天
Am             F
你低头笑得很浅

F              G
我把没说出口的话
Em             Am
写进旧吉他的弦
```

### 3. AI 改编

用户可点击：

## 九、AI 提示词模板

### 1. AI 写歌提示词

```text
你是一名专业流行音乐创作人、吉他编曲老师和中文歌词创作者。

请根据用户输入，生成一首适合吉他弹唱的原创歌曲。

要求：
1. 必须是原创内容，不模仿或复制已有歌曲歌词。
2. 输出歌名。
3. 输出风格、调式、BPM、变调夹建议、难度。
4. 歌词结构包含主歌、副歌，可选桥段。
5. 每句歌词上方标注对应和弦。
6. 和弦优先使用新手友好和弦，例如 C、G、Am、F、Em、Dm。
7. 给出右手节奏型。
8. 给出练习建议。
9. 输出必须是 JSON 格式，方便小程序渲染。
10. 不要输出解释性废话。

用户需求：
{{user_input}}
```

### 2. 歌词配和弦提示词

```text
你是一名专业吉他编曲老师。

请为用户提供的歌词自动配置适合吉他弹唱的和弦。

要求：
1. 保持歌词原文不变。
2. 每句歌词上方添加和弦。
3. 推荐调式、BPM、变调夹位置。
4. 优先使用新手友好和弦。
5. 输出主歌、副歌等结构。
6. 给出扫弦或分解节奏建议。
7. 输出 JSON 格式。
8. 不要生成已有商业歌曲的完整歌词或完整曲谱；如检测到疑似版权歌曲，只提供学习建议或片段分析。

用户歌词：
{{lyrics}}
```

### 3. AI 改编提示词

```text
你是一名吉他编曲老师。

请根据已有弹唱谱进行改编。

改编目标：
{{rewrite_goal}}

要求：
1. 保持歌曲主题和段落结构。
2. 根据目标调整和弦难度、节奏型、调式或风格。
3. 输出完整的新版本弹唱谱。
4. 标注与原版本不同之处。
5. 输出 JSON 格式。
```

## 十、版权与合规策略

### 风险点

| 风险 | 说明 |
|---|---|
| 热门歌曲完整曲谱 | 可能涉及曲谱版权 |
| 完整歌词展示 | 可能涉及歌词版权 |
| 上传原曲扒谱 | 可能涉及音乐版权 |
| 用户公开分享侵权谱 | 平台有审核责任 |

### 建议策略

第一版主打：

```text
AI 原创弹唱谱
```

不主打：

```text
全网热门歌曲曲谱库
```

规则建议：

1. 用户输入疑似热门歌曲名称时，提示仅生成“练习建议”或“风格化原创”。
2. 不直接展示完整商业歌曲歌词。
3. 用户上传内容默认设为私密。
4. 公开广场只允许原创作品。
5. 增加举报和审核机制。
6. 后期如果做曲库，要走授权或合作。
