## 2. 首页

### 页面目标

让用户在 3 秒内理解产品能力：AI 可以写歌、生成吉他谱、辅助练习。

### 页面结构

```text
顶部区域
- Logo：谱灵 AI
- 搜索框：搜索歌曲 / 输入灵感
- 消息或历史入口

主视觉 Banner
- 标题：让 AI 帮你写一首能弹唱的歌
- 副标题：输入灵感，生成歌词、和弦、节奏和吉他谱
- 主按钮：开始 AI 写歌
- 次按钮：粘贴歌词配和弦

快捷功能区
- AI 写歌
- AI 配和弦
- 生成吉他谱
- 练习模式

内容推荐区
- 今日灵感
- 新手必弹
- 热门 AI 原创
- 弹唱技巧
```

### 交互说明

- 点击搜索框：进入搜索页，支持搜索曲谱和输入灵感。
- 点击开始 AI 写歌：进入 AI 写歌页。
- 点击粘贴歌词配和弦：进入 AI 配和弦页。
- 点击热门作品：进入曲谱详情页。

## 3. AI 写歌页

### 页面目标

让用户用一句话生成原创弹唱作品。

### 页面结构

```text
标题区
- AI 写一首能弹唱的歌
- 示例提示词轮播

输入区
- 多行文本框
- placeholder：比如“写一首关于毕业、夏天和遗憾的校园民谣”

参数区
- 风格：民谣 / 流行 / 校园 / 摇滚 / R&B
- 难度：新手 / 进阶 / 专业
- 调式：自动 / C / G / D / Am
- 语言：中文 / 英文 / 中英混合

底部按钮
- 生成弹唱谱
```

### 交互说明

- 输入为空时，按钮置灰。
- 生成中显示加载动画和创作提示。
- 生成失败时保留用户输入，提示重新生成。
- 生成成功后进入生成结果页。

## 4. AI 配和弦页

### 页面目标

用户粘贴歌词后，AI 自动生成适合吉他弹唱的和弦谱。

### 页面结构

```text
顶部说明
- 粘贴歌词，AI 自动配和弦

歌词输入区
- 多行文本框
- 支持粘贴
- 字数统计

参数区
- 调式：自动 / C / G / D / A / Am
- 难度：新手 / 进阶
- 节奏：自动 / 扫弦 / 分解

底部按钮
- 开始配和弦
```

### 风险提示

如果用户粘贴疑似商业歌曲完整歌词，系统应提示：

```text
为避免版权风险，当前仅支持原创歌词配和弦，或提供片段学习建议。
```

### 页面结构

```text

- 返回
- 歌名
- 设置

曲谱显示区
- 大字号歌词与和弦
- 当前段落高亮
```

- 滚动速度调整
- 暂停/继续
