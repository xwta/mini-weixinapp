# 谱灵 AI 小程序开发路线图 V1.0

## 1. 总体目标

用最短路径完成一个可以内测的小程序 MVP：

```text
用户登录 → 输入灵感/歌词 → AI 生成弹唱谱 → 保存作品 → 查看曲谱 → 收藏/分享
```

## 2. 阶段规划

## Phase 0：产品与技术准备

预计周期：2-3 天

目标：明确产品边界，确定技术方案，建立项目骨架。

任务：

- 完成 PRD
- 完成页面原型文档
- 完成 API 文档
- 完成数据库设计
- 确定技术栈
- 创建前端/后端项目结构
- 配置代码规范

交付物：

- docs/PRD.md
- docs/WIREFRAME.md
- docs/API.md
- docs/DATABASE.md
- 前后端项目初始化

## Phase 1：MVP 核心闭环

预计周期：2-3 周

目标：完成 AI 创作核心链路。

### 小程序端

- 首页
- AI 写歌页
- AI 配和弦页
- 生成结果页
- 曲谱详情页
- 我的页面
- 我的作品页
- 收藏列表页

### 后端

- 微信登录
- 用户信息接口
- AI 写歌接口
- AI 配和弦接口
- 曲谱保存接口
- 曲谱详情接口
- 我的作品接口
- 收藏接口
- 免费次数限制

### AI 能力

- AI 写歌 prompt
- AI 配和弦 prompt
- JSON 输出格式校验
- 生成失败重试
- 内容安全初筛

验收标准：

- 用户可登录
- 用户可生成一首原创弹唱谱
- 用户可保存和查看生成结果
- 用户可收藏作品
- 免费用户生成次数可限制

## Phase 2：练习体验增强

预计周期：1-2 周

目标：提升真实弹唱场景体验。

任务：

- 自动滚谱
- 字体大小调整
- 滚动速度调整
- 节拍器
- 升降调
- 变调夹建议
- 最近练习记录

验收标准：

- 曲谱详情页可进入练习模式
- 用户可控制滚谱速度
- 用户可调整字体大小
- 系统记录最近练习歌曲

## Phase 3：商业化版本

预计周期：1-2 周

目标：完成基础收费闭环。

任务：

- 商品套餐配置
- 微信支付接入
- 创建订单
- 支付回调
- 次数包发放
- 会员有效期
- 会员中心页
- 生成次数扣减

验收标准：

- 用户可购买次数包
- 支付成功后次数到账
- 会员权益可识别
- AI 生成前可校验次数

## Phase 4：分享与传播

预计周期：1 周

目标：增强小程序自然传播。

任务：

- 分享海报生成
- 小红书文案生成
- 抖音/视频号文案生成
- 邀请好友奖励
- 热门 AI 原创推荐

验收标准：

- 用户可生成曲谱海报
- 用户可复制分享文案
- 用户可通过分享进入曲谱详情或创作页

## Phase 5：后台管理

预计周期：1-2 周

目标：保证内容、用户、订单可管理。

任务：

- 用户管理
- 曲谱管理
- AI 生成记录
- 订单管理
- 内容审核
- 举报处理
- 数据看板

验收标准：

- 管理员可查看用户和作品
- 管理员可审核公开作品
- 管理员可查看订单和支付状态
- 管理员可查看 AI 成本数据

## Phase 6：社区与高级 AI 能力

预计周期：后续迭代

目标：从工具升级为内容社区。

可选功能：

- 原创作品广场
- 点赞与评论
- 用户关注
- 用户上传曲谱
- 音频和弦识别
- 哼唱生成旋律
- AI 生成前奏/间奏
- PDF 导出

## 5. 风险与应对

| 风险 | 应对 |
|---|---|
| AI 输出不稳定 | 使用 JSON schema 校验和重试机制 |
| 版权风险 | 主打原创，不展示商业歌曲完整歌词和曲谱 |
| 生成成本过高 | 免费次数限制、缓存、会员付费 |
| 微信审核不通过 | 避免侵权曲库描述，强调原创工具 |
| 用户不知道怎么输入 | 提供示例提示词和快捷模板 |
