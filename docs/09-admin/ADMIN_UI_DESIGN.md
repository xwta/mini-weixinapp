# 谱灵 AI 管理后台 UI 设计方案

## 1. 后台定位

管理后台用于支撑谱灵 AI 的内容审核、用户运营、AI 成本监控、商业化管理和数据分析。

后台不是小程序的简单附属页面，而是运营团队每天使用的工作台。

## 2. 技术栈建议

```text
Vue 3
TypeScript
Vite
Element Plus
Pinia
ECharts
Axios
```

## 3. 信息架构

```text
管理后台
├── 工作台 Dashboard
├── 用户管理
├── 曲谱管理
├── 评论管理
├── 内容运营
├── AI 成本中心
├── 订单与会员
├── 数据分析
├── 系统通知
└── 系统设置
```

## 5. 视觉规范

后台采用轻量专业风格：

```text
背景：#F6F8FA
主色：#1E7A5A
文字主色：#1F2428
辅助文字：#687078
警告色：#F59E0B
错误色：#E5484D
成功色：#22A06B
```

布局：

```text
左侧固定导航 240px
顶部栏 64px
内容区域 24px padding
卡片圆角 12px
表格行高 52px
```
