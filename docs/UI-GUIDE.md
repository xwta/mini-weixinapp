# 谱灵 AI 小程序 UI 视觉规范 V1.0

## 1. 设计关键词

```text
年轻 / 清爽 / 音乐感 / AI 智能感 / 新手友好 / 创作氛围
```

整体避免传统工具站风格，不做沉重黑金风，也不做高饱和刺眼科技蓝。

## 2. 视觉定位

产品应该像一个“会写歌的吉他练习本”：

- 白色背景为主
- 奶油色与浅绿色辅助
- 深绿色作为品牌主色
- 局部加入木吉他、纸张、音符、声波元素
- AI 感通过渐变、光晕、灵感卡片表现，不做赛博废土感

## 4. 字体规范

小程序默认使用系统字体。

```text
iOS：PingFang SC
Android：Noto Sans CJK / 系统默认中文字体
数字：DIN 风格优先，如不可用则使用系统字体
```

字号建议：

| 场景 | 字号 | 字重 |
|---|---:|---|
| 首页大标题 | 28-32px | 700 |
| 页面标题 | 22-24px | 600 |
| 卡片标题 | 18-20px | 600 |
| 正文 | 15-16px | 400 |
| 辅助说明 | 12-14px | 400 |
| 曲谱正文 | 17-20px | 500 |
| 和弦行 | 15-18px | 700 |

## 5. 圆角与阴影

```text
小按钮圆角：12px
卡片圆角：20px
大卡片圆角：28px
底部弹窗圆角：24px 24px 0 0
```

阴影建议：

```css
box-shadow: 0 8px 24px rgba(18, 60, 50, 0.08);
```

## 6. 组件规范

### 6.1 主按钮

```text
背景：#1E7A5A
文字：#FFFFFF
高度：48px
圆角：16px
字重：600
```

状态：

| 状态 | 样式 |
|---|---|
| 默认 | 品牌绿背景 |

```text

```

```text

```

## 7. 曲谱排版规范

曲谱页是产品的“琴弦中枢”，需要非常清晰。

### 基础信息区

```text
歌名：24px / 700
标签：风格、难度、AI原创
调式/BPM/变调夹：卡片式展示
```

### 曲谱正文

建议使用等宽排版或接近等宽的视觉结构。

```text
段落标题：主歌 / 副歌 / 桥段
和弦行：品牌绿、加粗
歌词行：正文黑
行距：1.8
段落间距：24px
```

示例：

```text
主歌

C              G
操场边的风吹过了盛夏
Am             F
你低头笑着没有回答
```

## 8. 图标风格

图标建议使用线性图标，圆角端点。

常用图标：

- 吉他
- 音符
- 魔法笔
- 星光
- 收藏
- 分享
- 节拍器
- 播放/暂停
- 文档
- 用户

## 9. 动效建议

### AI 生成中

表现方式：

- 光点缓慢流动
- 音符轻微漂浮
- 文案轮播

生成文案：

```text
正在寻找适合你的和弦...
正在把灵感写进旋律...
正在调整适合新手的节奏型...
```

### 页面切换

- 轻微上滑进入
- 卡片淡入
- 按钮按压缩放 0.98

## 10. 首页视觉建议

首页第一屏建议结构：

```text
浅纸白背景
顶部 Logo + 搜索框
大标题：让 AI 帮你写一首能弹唱的歌
副标题：输入灵感，生成歌词、和弦、节奏和吉他谱
主按钮：开始 AI 写歌
右侧/背景：抽象吉他弦 + 音符 + AI 光点
```

## 11. 禁止事项

- 不使用大面积暗黑背景作为主视觉。
- 不使用高饱和荧光绿。
- 不使用传统商务蓝。
- 不使用过度复杂的 3D 科技球。
- 不在曲谱正文区域加入干扰阅读的装饰。
- 不让 AI 元素喧宾夺主，音乐创作才是主角。

## 12. 小程序适配建议

- 主要内容区域左右边距：16px。
- 底部按钮避免贴近安全区。
- 弹唱练习模式需要支持大字号。
- 安卓设备注意字体粗细和行高兼容。
- 长曲谱页面需要保证滚动流畅。
