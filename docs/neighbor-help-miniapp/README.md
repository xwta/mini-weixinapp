# 邻里帮帮：社区邻里互助小程序资料包

本目录用于沉淀「社区邻里互助小程序」的产品规划资料，方便后续开发、报价、原型设计和商业包装。

## 当前文件

- `PRD_V1.0.md`：产品需求文档，包含产品定位、目标用户、核心功能、业务流程、订单状态、后台模块、支付结算、风控和版本规划。
- `MVP_CHECKLIST.md`：第一版开发清单，方便拆分开发任务和报价。
- `OPERATION_PLAN.md`：冷启动运营方案，方便先跑一个小区验证订单。

## 产品一句话

不想下楼的小事，都有人帮你跑。

## 第一版建议重点

第一版不要做成“大而全”的社区平台，先做能真实跑单的轻量交易闭环：

1. 用户能下单并支付
2. 接单员能抢单并完成
3. 平台能管理订单并结算

优先服务类目：

- 帮取快递
- 送水上楼
- 代扔垃圾
- 取餐/取咖啡/取奶茶
- 商品代买
