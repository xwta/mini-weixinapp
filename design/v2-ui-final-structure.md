# 谱灵 AI V2 最终 UI 结构说明

## 1. 设计定位

V2 版本从传统多页面工具型小程序，升级为对话式 AI 吉他伙伴。

核心体验：

```text
用户输入需求
  ↓
AI 自动识别意图
  ↓
切换能力模式
  ↓
生成曲谱 / 搜索曲谱 / 配和弦 / 指导练习
  ↓
保存记录 / 分享社区 / 继续修改
```

## 2. 一级 Tab

一级 Tab 只保留三个：

```text
谱灵
社区
我的
```

说明：

```text
记录不是一级 Tab
记录是谱灵首页的二级页面
```

## 3. 一级页面

### 3.1 谱灵首页

定位：AI 对话工作台。

包含：

```text
顶部模式切换
AI 对话区
结果卡片
输入框
记录入口
底部 Tab
```

模式：

```text
AI写歌
搜谱
配和弦
练习助手
乐理问答
```

### 3.2 社区首页

定位：内容广场与音乐交流社区。

包含：

```text
搜索框
推荐 / 关注 / 最新 / 热门
作品流
发布入口
点赞 / 评论 / 收藏 / 分享
```

### 3.3 我的首页

定位：个人资产与账号中心。

包含：

```text
用户信息
AI额度
我的作品
我的收藏
我的发布
练习记录
消息通知
会员中心
设置中心
```

## 4. 二级页面

```text
谱灵记录页
社区搜索页
曲谱详情页
练习模式页
发布作品页
```

## 5. 三级页面

```text
话题详情页
用户主页
消息详情页
设置详情页
```

## 6. 页面关系

```text
谱灵首页
├── 记录页
├── 模式切换弹层
├── 曲谱详情页
└── 练习模式页

社区首页
├── 社区搜索页
├── 发布作品页
├── 话题详情页
├── 用户主页
└── 曲谱详情页

我的首页
├── 我的作品
├── 我的收藏
├── 消息通知
├── 会员中心
└── 设置中心
```
